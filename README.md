# beliczki.hu

Personal portfolio website for Balazs Beliczki - AI Engineer

## Overview

A clean, professional one-pager showcasing AI engineering projects and expertise.

## Features

- **Mobile-First Design**: Fully responsive layout optimized for all devices
- **Clean & Professional**: Minimalist design focusing on content
- **Fast Loading**: No heavy frameworks, just pure HTML/CSS with Lucide icons
- **Accessibility**: Semantic HTML and proper contrast ratios

## Structure

## Design Principles

- **Simple & Clean**: Focus on content, minimal distractions
- **Professional**: Humble, straightforward presentation
- **Responsive**: Works on all screen sizes (mobile-first)
- **Fast**: Lightweight, optimized loading

## Technologies

- HTML5
- CSS3 (CSS Custom Properties)
- Lucide Icons
- No JavaScript frameworks

## Local Development

Simply open `index.html` in your browser. No build process required.

## Deployment

### GitHub Pages

1. Push to GitHub repository
2. Go to repository Settings > Pages
3. Set source to main branch
4. Your site will be live at https://beliczki.hu

### Custom Domain Setup

1. Add a `CNAME` file with your domain
2. Configure DNS:
   - Add A records pointing to GitHub Pages IPs
   - Or add CNAME record pointing to `beliczki.github.io`
